Batch Upload Literature

Upload a manifest (CSV or Excel) with one row per paper, or a JSON / JSONL file with one record per paper. Each record is committed through the same path as the manual literature form, so DOIs are de-duplicated automatically.

JSON uploads keep their structured elements and synthesis_steps intact. A CSV manifest carries only a free-text synthesis route, so prefer JSON when you have step-level detail.
