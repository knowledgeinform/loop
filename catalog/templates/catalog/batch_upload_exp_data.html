Batch Upload Experimental Data

Upload a manifest CSV together with a ZIP of experiment folders. Each manifest row is matched to a folder (e.g. SP15M-001) and committed through the same path as the manual add form — so duplicate raw files are detected by hash automatically. You can also upload only a ZIP to generate a manifest template.
